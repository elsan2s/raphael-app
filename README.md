# Raphael Overlay — APK pelo celular

Este projeto está pronto para gerar um APK instalável pelo GitHub Actions, sem precisar de PC.

## Como gerar o APK no Moto G32

1. Baixe este ZIP e descompacte.
2. Crie uma conta no GitHub, se ainda não tiver.
3. No GitHub pelo navegador do celular, crie um repositório novo chamado `raphael-overlay`.
4. Envie todos os arquivos deste projeto para o repositório.
5. Vá em **Actions**.
6. Abra **Build APK**.
7. Toque em **Run workflow**.
8. Depois que terminar, abra a execução e baixe o artifact **Raphael-debug-apk**.
9. Extraia o ZIP do artifact. Dentro estará `app-debug.apk`.
10. Instale o APK no Moto G32.

## Depois de instalar

1. Abra o app.
2. Toque em **Iniciar Raphael**.
3. Libere a permissão de sobrepor outros apps.
4. Abra o Mobile Legends.
5. Use o botão flutuante **Raphael**.

## Observação

Este app não lê a tela, não joga por você e não automatiza ações. Ele é um overlay manual de dicas rápidas.
